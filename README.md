# Simulador-intelegente-de-Solicitacoes-com-IA
obre o projeto  Projeto de automação desenvolvido com n8n e inteligência artificial para simular o recebimento, a análise e o registro de solicitações empresariais.  O fluxo recebe informações por meio de um formulário, utiliza um agente de IA para analisar a solicitação e registra os dados em uma planilha.

Tecnologias utilizadas

- n8n
- OpenAI
- Google Sheets
- JSON
- Engenharia de prompts

Funcionamento

1. O usuário preenche o formulário.
2. O agente de IA analisa a solicitação.
3. O analisador de saída organiza o resultado.
4. Os dados são encaminhados para uma planilha.

Como executar

Importe o arquivo "workflow-n8n.json" no n8n e configure suas próprias credenciais para os serviços utilizados.

A configuração pode exigir uma conta e uma chave de API da OpenAI, além de acesso ao Google Sheets.

Observações

Este projeto utiliza dados de teste e tem finalidade educacional e de portfólio. Não inclui credenciais privadas.
